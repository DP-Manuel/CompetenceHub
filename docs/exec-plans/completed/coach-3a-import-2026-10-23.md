## Design Boundaries

No second Coach model, new taxonomy API or import HTTP endpoint. Existing
versioned children remain snapshots; import item keys distinguish logical
catalogue identity from physical snapshot rows. Unknown source fields fail closed.
Roles/qualifications/boundaries require explicit reviewed literal-text mapping
or a classified gap, never automatic tags/clinical interpretation. This does
not settle lossless real-profile rendering or historic-consent decisions.
